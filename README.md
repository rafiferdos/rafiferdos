## 🚀 Selected Work

### 01. SpotFix — Service Booking Platform

A service marketplace built around real booking workflows rather than a simple CRUD dashboard.

It separates the product into **Admin, Customer, and Technician experiences**, with protected role-based flows for service management, technician availability, bookings, payments, and reviews.

**What it demonstrates:**
- Multi-role product architecture and protected dashboards
- Dynamic technician availability and booking workflows
- Payment success/cancellation flows
- Review and rating system
- Feature-based frontend architecture with reusable API hooks and types
- Form validation, server-state handling, responsive UI, and theme support

**Stack:** `Next.js` · `TypeScript` · `TanStack Query` · `Axios` · `React Hook Form` · `Zod` · `shadcn/ui` · `Tailwind CSS`

### 02. Lunaris — Assessment & Interview Practice Platform

A full-stack assessment platform built to handle **scoring, XP, ratings, quotas, rankings, attempt recovery, integrity signals, and real-time leaderboard updates** on the server instead of trusting the browser.

The frontend and backend use a typed API contract, while important actions such as attempt creation, scoring, finalization, ranking, and authorization remain server-owned.

**What it demonstrates:**
- Next.js frontend connected to a standalone Hono API
- PostgreSQL persistence with Drizzle ORM
- Better Auth cookie-based sessions and server-enforced authorization
- Server-side scoring, XP, ratings, quotas, and attempt finalization
- Retry-safe and idempotent assessment workflows
- Resumable assessments with persisted answers and server-aligned timers
- Live leaderboard updates through SSE
- Cross-tab assessment protection and integrity event handling
- Optional local voice-activity detection without uploading recordings
- OpenAPI-generated TypeScript contracts
- Admin JSON validation/import flows
- Unit, integration, smoke, and Playwright E2E testing
- Docker-based local infrastructure and CI-ready validation

**Stack:** `Next.js` · `TypeScript` · `Hono` · `PostgreSQL` · `Drizzle ORM` · `Better Auth` · `TanStack Query` · `OpenAPI` · `Zod` · `SSE` · `Docker`

### 03. Trendora — Second-Hand Marketplace

A responsive marketplace frontend for buying and selling second-hand products, connected to backend APIs for authentication, listings, transactions, and account-level actions.

**What it demonstrates:**
- Product listing creation, browsing, updating, and deletion
- Category-based discovery, search, and filtering
- JWT-backed authentication and protected user flows
- Role-based access control
- Purchase and transaction flows through REST APIs
- Reusable frontend structure with services, hooks, providers, and typed models
- Responsive marketplace UI across screen sizes

**Stack:** `Next.js 15` · `TypeScript` · `REST APIs` · `JWT` · `shadcn/ui` · `Tailwind CSS`
